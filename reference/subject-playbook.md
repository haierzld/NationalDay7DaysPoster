# 非国家主体的素材检索手册

主体是城市、学校、企业时，**不能凭记忆直接写素材**，必须先检索并落地成素材库 JSON。

## 1. 流程

1. `python scripts/nd7.py subject "<用户输入>"` 得到类型、slug、7 大主题与合规提醒
2. 逐主题联网检索，凑齐 28 个条目（Day1 需 1 条 … Day7 需 7 条）
3. 交叉核验：名称、地点、时间/年代至少两个独立来源；无法核实就换同类备选
4. 写入 `config/subjects/<slug>.json`
5. `python scripts/nd7.py plan --subject "<主体名>" --out outputs/<slug>-prompts.md`

## 2. 主题清单

| 类型 | 7 大主题 |
| --- | --- |
| 城市 | 城市地标与天际线；重大工程与交通枢纽；产业园区与科技创新；生态水系与公园绿地；历史人文与非遗民俗；民生服务与市井烟火；夜景灯光与未来规划 |
| 学校 | 校门与标志性建筑；校园风景与学习空间；课堂与学科特色；实验室与科研平台；体育社团与校园文化；校史沿革与荣誉陈列（不出现人物）；国际交流与未来愿景 |
| 企业 | 品牌理念与总部形象；核心产品与解决方案；智能产线与工厂制造；研发创新与专利墙（抽象化）；团队协作与办公空间；绿色低碳与社会责任；全球化布局与未来愿景 |

城市示例（福州）：三坊七巷 → 闽江两岸天际线 → 滨海新城与数字福建产业园 → 闽江河口湿地 → 茉莉花茶与脱胎漆器非遗 → 地铁与市民生活 → 闽江夜景灯光秀 …… 共 28 条。

学校也可直接用“校园风景 7 幅”：校门、图书馆、湖畔、林荫道、操场、实验楼、雪景/夜景。

## 3. 素材库 JSON 模板

```json
{
  "subject": "福州",
  "type": "city",
  "year": 2026,
  "source": "检索来源与日期（写到这一行，便于复核）",
  "days": [
    {
      "day": 1,
      "signature": "2026.10.01 庆祝中华人民共和国成立77周年",
      "events": [
        {"title": "三坊七巷", "scene": "晨光中的三坊七巷坊巷格局，白墙黛瓦与马鞍墙，石板路与红灯笼"}
      ]
    },
    {
      "day": 2,
      "signature": "10.02 祝福祖国",
      "events": [
        {"title": "闽江两岸天际线", "scene": "..."},
        {"title": "福州滨海新城", "scene": "..."}
      ]
    }
  ]
}
```

字段说明：

- `subject`：与 `--subject` 传入的名字完全一致（脚本靠它匹配文件）
- `type`：`city` / `school` / `company`（会自动追加对应的合规负面词）
- `days`：7 天，每天的 `events` 条数必须等于 `day`
- `title`（可选）：当日金色书法主标题，如 `盛世华章·祖国万岁`；缺省时回落到全局默认主标题
- `signature` / `signature2`（可选）：底部两行落款，如 `10.1` + `祝福祖国`；缺省为 `10.X 祝福祖国`

## 4. 合规要求

- 只使用官网、官方公众号、年报、权威媒体报道的公开信息
- 不编造排名、人数、升学率、专利号、财务数据、客户名称
- 不出现可识别的真实人物肖像；学生/员工用背影、剪影或空场景
- 不精确复刻校徽、商标、品牌 logo；需要体现时用抽象化、去标识化处理
- 不使用绝对化用语；不输出地图边界与国界线
- 事实以官方最新公告为准，检索日期写入 `source` 字段
