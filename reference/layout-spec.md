## 4. 素材条目写法

每个条目由 `title`（名称）+ `scene`（画面描述）组成。写法要求：

- 一句话说清主体、环境、光线、质感，约 30-60 字
- 只写可核验的客观事实，不写评价与数据
- 不写入需要在画框内显示的文字（画框内禁止文字）
- 避免人物特写；必须出现人时用背影、剪影或远景

示例：

```json
{"title": "平陆运河全线通航枢纽",
 "scene": "宽阔的运河航道与阶梯船闸群，货船列队有序通行，两岸生态绿岸与跨河大桥，清晨金色阳光洒在江面"}
```
